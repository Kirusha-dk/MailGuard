# v54

v53: 93,227% recall, 81 FP на 81 688 письмах. 2065 из 2458 пропусков приходится на TREC-05 и SetFit-Enron. Это анализ уже использованного инженерного набора, не независимая оценка.

v54 проверяет другую границу классификации: LinearSVC с C=0.1/1/4, штрафом ham=2 и двумя представлениями — TF-IDF и нормализованным NB-взвешенным TF-IDF. IDF и отношение классов обучаются только на TRAIN. Кандидат выбирается на чётной половине валидации; порог фиксируется на нечётной половине без повторного обучения. Все решения v51 сохраняются; при отсутствии выигрыша на валидации выбирается v51.

Бюджет дополнительных FP учитывает уже сделанные v51 ошибки, общий бюджет на калибровке — 0,0012 от числа писем. Первые 1000 строк проверяют работоспособность, полный запуск сравнивает модели на прежних наборах. Порог на тесте не подбирается. SVM-score — монотонное преобразование margin, не калиброванная вероятность.
