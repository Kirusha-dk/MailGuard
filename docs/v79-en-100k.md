# MailGuard v79: проверка 100 000 английских писем

На **десяти заранее зафиксированных блоках по 10 000 писем** режим `target-80` обнаружил не менее **81,35% спама в каждом блоке**. Всего найдено 38460 из 46697 спам-писем (82,36%); FP — **48 из 53303 обычных писем (0,09%)**. Режим `balanced` даёт минимум 93,72% по блокам, с 214 FP суммарно.

**80% на любой английской почте не достигнуты и не гарантируются.** Блоки содержат смесь исторических источников. На отдельном поднаборе Nazario-2025: `target-80` нашёл 71 из 258 фишинговых писем (27,52%), `balanced` — 130 из 258 (50,39%). Это существенное слабое место, несмотря на прохождение десяти смешанных блоков.

## Что изменено

- Обучение с нуля: word NBSVM, char NBSVM и TF-IDF + LinearSVC. TRAIN — 89 453 письма, SELECT — 22 614, CAL — 46 186. Символьная модель обучена на 30 750 письмах с ограничением по источнику. Веса источников и классов участвуют в обучении.
- На SELECT выбирается комбинация с учётом худшего источника. Окончательный порог учитывает общий CAL-бюджет FP и каждый источник с минимум 500 обычными письмами. Бюджеты CAL: 0,1%, 0,2%, 0,5% соответственно. Это не ограничения на произвольную будущую почту.
- Английский язык определяется fastText `lid.176.ftz`: первая метка `en`, оценка минимум 0,8. Неанглийские и неуверенно определённые тексты явно исключаются; они не становятся автоматически HAM. Короткие и смешанные английские тексты могут быть пропущены.
- Зафиксированы 100 000 канонически уникальных тестовых писем из 10 почтовых источников; 98 223 префиксные группы. Между TRAIN, SELECT, CAL и TEST нет пересечений идентичностей и групп первых 45 слов. Проверены все идентификаторы и отпечатки. Все смысловые повторы этим не исключаются.
- Семейства прежнего официального TEST и опубликованного v78 TEST допущены только в development. Но публичные корпуса могли встречаться в старых версиях проекта. Источники обучения и TEST пересекаются: это проверка новых для свежего обучения писем внутри известных источников. Отдельная проверка на почте заказчика не выполнена.
- Новый объединённый набор locuoco содержит письма и текстовые сообщения с неполным происхождением. Его неизвестные строки используются **только в development**. В финальный TEST они не входят. На 1 153 канонических совпадениях с исходными корпусами метки согласованы; это не аудит каждой неизвестной строки. Противоречивые идентичности удаляются целиком. Источник sniff07 остаётся исключённым.
- Модель и пороги сохранены до оценки блоков. SHA256 до и после TEST одинаков. После просмотра теста пороги не менялись. На всех блоках использовалась одна и та же модель.

Предыдущая v78 проверялась на другом наборе, поэтому её цифры нельзя напрямую сравнивать с этой таблицей. [Прежняя версия и результаты](v78-en.md) сохранены.

## Запуск на своих письмах

Нужен Python 3.12. Скачайте архив весов v79 и распакуйте его в `model`, чтобы появился `model/model.joblib`.

```bash
git clone --branch mailguard-v79-en-100k --single-branch https://github.com/Kirusha-dk/MailGuard.git
cd MailGuard
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-v79.txt
python tools/v79_mail.py \
  --model model/model.joblib \
  --spam mail/spam --ham mail/ham \
  --profile target-80 --output results/check-01
```

Одно письмо — один `.eml`; папки HAM и SPAM должны быть раздельными. Отчёт содержит `summary.json` и `predictions.csv` без текстов писем. Повторы по каноническому тексту исключаются; при противоречивых метках удаляются обе копии. Для `balanced` укажите другую выходную папку. Обработка работает на CPU локально без сети и PyTorch после установки зависимостей.

SHA256 `model.joblib`:

```text
f331dc14cb289a5e27cc96904aad519cc07bc2a400e008ea71acffd200621d72
```

Проверены 24 теста v77/v78/v79 и запуск настоящей модели через MIME CLI на 60 отложенных английских письмах. CLI совпал с API; французское, немецкое и русское письма исключены, пунктуационный повтор и противоречивые метки обработаны.

## Повторить подготовку и обучение

```bash
python -m pip install -r requirements-v79-training.txt
python tools/fetch_v79_sources.py --archive /absolute/path/new-sources.zip
python tools/v79_data.py --archive /absolute/path/new-sources.zip
python tools/audit_v79_frozen.py --output reports/v79-data-audit.json
OMP_NUM_THREADS=3 OPENBLAS_NUM_THREADS=3 MKL_NUM_THREADS=3 \
  python -u tools/train_v79_en.py --out reports/v79
python -m unittest discover -s tests/python -p 'test_v7[789]*.py' -v
```

Запускайте в новой рабочей копии: подготовка и обучение не перезаписывают готовые выборки и отчёты. Для обучения проверены Linux, Python 3.12 и 8 ГБ памяти. Установка fasttext-wheel на других платформах отдельно не проверялась.

ZIP исходных архивов должен содержать `genspam.tar.gz`, `nazario-2025.mbox`, `labelled-mail.zip`; каждый проверяется по SHA256. Источники: [GenSpam](http://www.cl.cam.ac.uk/Research/NL/nl-download/GenSpam.tar.gz), [Nazario-2025](https://monkey.org/~jose/phishing/phishing-2025), [labelled email, закреплённый commit](https://github.com/realprogrammersusevim/email-dataset/tree/84209612df4c55831f074a65b7c137a4b980059d). Последний ZIP — архив этого commit с GitHub, переименованный в `labelled-mail.zip`. Объединённый набор и LID загружаются скриптом по закреплённым версиям и суммам. Исходный семикорпусный набор: [JinqiangDing/seven-phishing-email-datasets](https://huggingface.co/datasets/JinqiangDing/seven-phishing-email-datasets), revision `deb4cc27dc2754c14cb157aace412727f77b41dd`.

Исходные письма и веса не включены в Git. Веса передаются отдельным архивом. В него включён неизменённый fastText LID под CC BY-SA 3.0: [атрибуция](fasttext-attribution.txt). Старые версии сохранены.
