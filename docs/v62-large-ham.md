# Большая проверка ложных срабатываний v62

GitHub Actions: **MailGuard v62 large legitimate-mail FP test**. Модель и пороги v62 не меняются. Эта проверка измеряет FP на обычной почте; распознавание спама оценивается отдельными наборами.

Источники — размеченные HAM-письма из `JinqiangDing/seven-phishing-email-datasets` и оригинального китайского TREC06. Ревизия Hugging Face, хэши архива и индекса исходных меток сохраняются до классификации.

Берутся все пригодные письма, а не копии до заданного круглого числа. Исключаются идентификаторы и семейства TRAIN/SELECT/CAL, повторы тел и нормализованных шаблонов, конфликтующая разметка. Проверяются также варианты старой декодировки. Не размеченная корпоративная почта не считается автоматически HAM.

В отчёте отдельно указаны:

- все проверенные HAM;
- письма, связанные с ранее проверенными инженерными наборами v62;
- дополнительные письма;
- FP/FPR для обоих профилей по источникам и письменности;
- верхняя граница 95% интервала FPR по методу Wilson.

Публичные исторические источники уже изучались при разработке. Дополнительные письма не являются новым независимым набором заказчика. Переписка и похожие письма могут оставаться связанными даже после удаления точных повторов.

Результаты: `reports/v62-large-ham-result.json` и `.md`, артефакт `mailguard-v62-large-ham-result`. `false-positives.csv` содержит идентификаторы и оценки ошибочно заблокированных писем без их текстов. Замороженный корпус и результаты сохраняются также в отдельном черновике Release для владельца.
