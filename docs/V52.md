# v52 learned word/bigram representation

v51 achieved 93.16% recall and 80 FP on 81,688 historical engineering rows.
The target remains 98% recall and <=100 FP on 100k, which has not been reached.

The byte CNN only reads 1024 UTF-8 bytes at each end of canonical text. v52
tests a broader representation: up to 768 words across head/middle/tail plus
adjacent word pairs inside each window. No fake bigrams join remote windows.
Deterministic hashes map tokens to 65,535 trainable embedding entries. Mean
and max pooling feed a supervised small neural classifier. This learns lexical
patterns; it is not a pretrained semantic language model.

The audited v50 data/training recipe is reused to isolate representation:
TRAIN only for gradients, selection validation for epoch/blend choice,
separate calibration validation for threshold, then frozen engineering test.
Weight-zero v48 is retained among blend candidates. This experiment does not
automatically replace v51; actual recall, FP and source results decide whether
it is useful. Test labels are never added to training.

Eight epochs follow the 1000-row/two-epoch smoke run. Local syntax and tokenizer
checks passed. Neural gradient tests run on GitHub after CPU Torch installation.
The historical pool still has only 81,688 rows. A successful workflow is not a
100k quality pass or a production stability claim.
