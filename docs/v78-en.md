# MailGuard v78: только английские письма

На отдельном наборе из **10 000 английских писем GenSpam** заранее зафиксированный режим `balanced` обнаружил **83,32% спама**. Обычных писем, ошибочно названных спамом, — **70 из 2 783 (2,52%)**. Это результат на одном историческом корпусе, не гарантия для произвольной почты.

## Результат настоящего запуска

В наборе 7 217 спам-писем и 2 783 обычных. Весь GenSpam, включая файлы с названием `train`, исключён из обучения, выбора модели и калибровки. Письма теста выбирались по хешу текста без учёта метки и результата классификатора.

| Модель | Режим | Найдено спама | Recall | FP / обычных | FPR |
|---|---|---:|---:|---:|---:|
| v77 | low-fp | 3 251 / 7 217 | 45,05% | 7 / 2 783 | 0,25% |
| **v78** | **low-fp** | **3 295 / 7 217** | **45,66%** | **6 / 2 783** | **0,22%** |
| v77 | balanced | 5 827 / 7 217 | 80,74% | 87 / 2 783 | 3,13% |
| **v78** | **balanced** | **6 013 / 7 217** | **83,32%** | **70 / 2 783** | **2,52%** |

В сравнении `balanced` v78 нашла на 186 спам-писем больше и дала на 17 ложных срабатываний меньше. Но 70 FP — много: низкая доля ложных срабатываний пока не достигнута. Более строгий режим сохраняет меньше FP ценой пропущенного спама. Порог после просмотра теста не менялся.

На CAL бюджет FPR равен 0,1% для `low-fp` и 0,5% для `balanced`. На внешнем тесте оба бюджета превышены. Это наблюдаемый перенос распределения, а не обещание, что установленный CAL-бюджет выполняется на каждом новом источнике.

## Исправление вывода по прошлому внешнему тесту

У прежнего внешнего источника `sniff07/phishing-dataset` обнаружены **9 673 канонических совпадения**, помеченных в исходных корпусах как HAM, а у этого поставщика — как SPAM. Ещё 6 241 совпадение имеет SPAM в обоих местах. Поэтому прежние 13,04% нельзя считать надёжной оценкой качества для задачи спам/HAM.

Сравнение проводится после нормализации с заменой URL, адресов и чисел. Оно не доказывает побайтовую идентичность исходных писем и не устанавливает, кто прав в каждом спорном случае. Вместо переименования меток по предсказаниям модели **весь источник исключён** из нового обучения и итоговой проверки. [Аудит с хешами и числом противоречий](../reports/v78-source-label-audit.json). Исторические отчёты сохранены.

## Обучение и ограничения проверки

- TRAIN: 73 939 английских писем из семи прежних почтовых корпусов и Nazario-2025. SELECT: 15 060. CAL: 18 000. Символьный классификатор использует 25 052 письма с ограничением размера каждого источника.
- Три классификатора: NBSVM по словам, NBSVM по символьным сочетаниям и TF-IDF + LinearSVC. Веса `(источник, класс)` реально участвуют в подсчёте NB-признаков и обучении SVM.
- Комбинация выбирается на SELECT, окончательный порог — по SELECT/CAL. Оба режима были определены до теста. Итоговые веса записаны и проверены по SHA256 до и после оценки.
- Пунктуационные варианты учитываются при дедупликации. Между TRAIN, SELECT, CAL и всем GenSpam нет пересечений по идентичности и префиксной группе первых 45 слов. Это не исключает все смысловые повторы.
- GenSpam — историческая анонимизированная почта. Корпус мог встречаться в более старых исследованиях проекта; v78 на нём не обучалась. Проверка на живой почте заказчика не выполнена.
- Только английский язык. Русские, прочие и слишком короткие тексты пропускаются с явным счётчиком, а не становятся автоматически HAM. Решение SVM — оценка, не вероятность.

## Проверить свои `.eml`

Нужен Python 3.12. Скачайте ветку `mailguard-v78-en` и распакуйте архив весов в `model`, чтобы появился файл `model/model.joblib`.

```bash
git clone --branch mailguard-v78-en --single-branch https://github.com/Kirusha-dk/MailGuard.git
cd MailGuard
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-v78.txt
```

Разложите размеченные письма по `mail/spam` и `mail/ham`. Команда для режима, который показал 83,32%:

```bash
python tools/v78_mail.py \
  --model model/model.joblib \
  --spam mail/spam --ham mail/ham \
  --profile balanced --output results/check-01
```

В `results/check-01` появятся `summary.json` и `predictions.csv`, без текстов писем. В сводке есть recall, FP, FPR и число пропущенных входных файлов. Повторы исключаются, обе копии противоречивой разметки исключаются. Для строгого режима замените `balanced` на `low-fp` и укажите новую выходную папку. Если `--profile` не задан, используется `low-fp`.

SHA256 файла `model.joblib`:

```text
0054c9642828618e6282a59c2b955ea747f38deba20d1e0729a7248ba2ed52a9
```

После установки зависимостей проверка писем работает локально, без сети и PyTorch. Проверены 17 тестов и запуск сохранённой модели через MIME CLI, включая явное исключение русского письма.

## Повторить обучение

Для первоначальной загрузки публичных источников нужны дополнительные зависимости:

```bash
python -m pip install -r requirements-v77.txt
python -m unittest discover -s tests/python -p 'test_v78_en.py' -v
python -u tools/train_v78_en.py --output reports/v78
```

При наличии локального ZIP с исходными `genspam.tar.gz` и `nazario-2025.mbox` используйте `--source-archive /absolute/path/new-sources.zip`. SHA256 исходных файлов проверяется. Исходные письма остаются в `.cache/`; в репозиторий публикуются код и агрегаты. Веса передаются отдельным архивом. Старые версии сохранены.
