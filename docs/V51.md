# v51: residual neural gate

Direct comparison of hash-matched v48 and v50 engineering predictions found:

| Change from v48 | Count |
|---|---:|
| Recovered spam | 680 |
| Newly missed spam | 387 |
| Added FP | 44 |
| Removed FP | 15 |

The net result was 293 additional detections and 29 additional FP. TREC-05
accounts for 268 recoveries, 151 regressions and 16 added FP; SetFit-Enron
accounts for 264 recoveries, 164 regressions and 7 added FP. CEAS adds 16 FP.
1596 of 2354 residual FN scored above .8 under v50's .9545 threshold, but
lowering that threshold on observed test labels would invalidate the test.

v51 preserves all original v48 spam decisions, rather than replacing scores
with an average. It learns a small precision gate from frozen sparse/neural
scores (logits, difference, product, minimum). Two logistic gates, a small
tree and a raw-neural gate compete with a no-rescue fallback.

Validation is split deterministically: quarter for gate fitting, quarter for
candidate selection, half for threshold calibration. The v50 CNN and v48
text estimator are frozen. The gate is not refit after calibration. The
threshold spends only allowance left after inherited v48 FP. If inherited
FP already exceeds the development allowance, rescue is disabled rather than
removing base decisions. Development allowance remains v48's .12% per total
validation population; it is not a test-FP guarantee.

The quality goal remains 98% recall and <=100 FP on 100,000 total mail. The
engineering pool is only 81,688 unique canonical rows, so a full-size pass
cannot be claimed. Test errors motivate the architecture but no engineering
test labels are used to fit gates or choose thresholds. Previous validation
has been used across iterations, including v50 epoch selection; therefore
validation and engineering scores do not replace a new independent test.

The classifier's score uses sentinel 2 for inherited spam decisions, with
rescue scores in [0,1]. It is a decision score, not a calibrated probability.
Neural and gate tests run in GitHub after CPU Torch installation; local
syntax checks cover all added files.
