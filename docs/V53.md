# v53

Дополнительная словесная проверка после v51. Все решения v51 сохраняются. Порог для WordNet v52 выбирается на нечётной половине валидации с учётом уже потраченного бюджета FP (0,0012 от числа писем). Если бюджет исчерпан, дополнительные решения отключаются.

Модели не переобучаются. Сначала проверка на 1000 письмах, затем фиксированные наборы. Тестовые метки не используются для выбора порога. Эти наборы уже применялись в разработке; результат служит сравнением версий, а не подтверждением качества на боевой почте.

Запуск: GitHub Actions → MailGuard v53 complementary lexical rescue. Модели, предсказания и отчёты сохраняются в mailguard-v53-evidence.
