RU: training_ready=false. Проверенные старые источники — Telegram/соцсети, переводы
либо SPAM-versus-phishing без HAM. Им нельзя присвоить вид реальных почтовых SPAM/HAM.
Сначала нужен размеченный native-RU email corpus. Пока workflow сохраняет причину
блокировки и ноль optimizer steps. Клиентскую почту запрещено загружать в Git/Actions
или внешние AI API; её можно обрабатывать лишь в разрешённой локальной среде заказчика.

Расписание ведёт одна отдельная задача ChatGPT для обоих новых языков, без cron-дублей.
Она проверяет фактические runs и изменяет только request следующей незавершённой даты
с rollback guard. Истечение окна и early stop уважаются, будущие даты не запускаются.
Artifacts сохраняются90 дней. В конце окна требуется долговременный экспериментальный
пакет адаптеров/checkpoint/metadata, а не только ссылка на истекающий artifact.
Автоматической замены стабильной v80 или production promotion нет.
